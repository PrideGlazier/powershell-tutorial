## 🎯 Why Learn PowerShell

Most shells pass text around. PowerShell passes **objects** — real .NET instances with properties and methods. That's what makes it uniquely powerful for automation.

| **Aspect** | **Bash / cmd** | **PowerShell** |
|------------|----------------|-----------------|
| **Data** | Plain text | Objects |
| **Pipelines** | Text streams | Object streams |
| **Cross-platform** | Linux/mac | ✅ Win/mac/Linux |
| **Automation** | Fragile | Robust |
| **Cloud** | Manual | Azure / AWS SDKs |
| **Learning curve** | Steep quirks | Consistent verbs |

## 🔧 Setup Walkthrough

### Step 1 — Install PowerShell 7
Download the latest stable release for your OS.

### Step 2 — Verify
Run `$PSVersionTable` to confirm.

### Step 3 — Set Execution Policy
`Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`.

### Step 4 — Install a Module
Try `Install-Module PSReadLine -Scope CurrentUser`.

### Step 5 — Write a Script
Create `hello.ps1` and run it.

### Step 6 — Schedule It
Use Task Scheduler or cron.

## 🌐 How To Use

### First Steps

1. **Install** PowerShell 7
2. **Explore** cmdlets with `Get-Command`
3. **Read** help with `Get-Help`
4. **Build** small pipelines
5. **Save** scripts
6. **Schedule** automation

### User Tips

- ✅ Learn Verb-Noun pattern
- ✅ Pipe objects, not text
- ✅ Use `Where-Object` and `ForEach-Object`
- ✅ Save snippets to a profile
- ✅ Test with `-WhatIf`

---

## 💡 Best Tips

- ✅ Use `Get-Help -Examples`
- ✅ Prefer `[CmdletBinding()]` in scripts
- ✅ Handle errors with `try/catch`
- ✅ Log with `Start-Transcript`
- ✅ Version-control your scripts

| **Problem** | **Solution** |
|--------------|---------------|

| **Encoding wrong** | Save as UTF-8 |
| **Remoting fails** | Enable WinRM / SSH |
| **Slow startup** | Clean profile |
| **Long path errors** | Enable long paths |
